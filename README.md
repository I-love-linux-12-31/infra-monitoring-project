## Этап 6. Настройка авторизации и передача архива. 

1. Создать ключ
```bash
ssh-keygen
```
2. Отправить публичный ключ на сервер к которому будем подключатся
```bash
ssh-copy-id -i <Путь к публичному ключу> user@host
```
3. Создать архив
```bash
tar -cJf <Файл project.tar.xz> .
```
4. Отправить на хост для деплоя
```bash
cp -i <ключ> <Файл ./project.tar.xz> <user@host:путь>
```
5. на хосте для деплоя разархивировать проект 
```bash
tar -xJf <Файл ./project.tar.xz>
```
6. Для деплоя. 
```bash
docker-compsoe up -d
```
7. Для проверки:
```bash
curl http://127.0.0.1:80
```
